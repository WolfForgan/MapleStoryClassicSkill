# 01 - 世界地图与移动系统

> **定位说明**：本文件讲清《冒险岛怀旧服》的世界结构——开放了哪些世界/大陆、各自定位与覆盖等级段、玩家怎么在世界间移动。读完本文件应能回答："这张地图属于哪个世界？这只怪在不在金银岛？从 A 到 B 怎么走？"

---

## 1.1 世界结构总览：本服开放的世界

《冒险岛怀旧服》是 2D 横版卷轴 MMORPG，游戏空间按**世界/大陆 → 区域 → 地图**三层组织。角色的旅程从**彩虹岛**（新手村）出发，乘船渡海抵达主大陆**维多利亚大陆（金银岛）**。**🔴 当前版本仅开放金银岛主大陆与黄金海滩**；神秘岛、玩具城、蘑菇城等高等级独立世界**尚未开放**。

| 世界/大陆 | 开放状态 | 定位 | 主要等级段 |
|---|---|---|---|
| **彩虹岛** | ✅ 开放 | 新手村：建角、教学、开局剧情起点 | Lv1~10/8（一转前） |
| **维多利亚大陆（金银岛）** | ✅ 开放（**当前唯一开放主大陆，含黄金海滩**） | **主大陆**：五大城镇、Lv1~70 绝大部分练级与任务内容；**黄金海滩已开放** | Lv1~70 |
| **神秘岛（El Nath，冰封雪域）** | ❌ **尚未开放** | 高等级区；预留资料：三转任务链的长老公馆所在地（三转亦未开放） | Lv70+（三转前后） |
| **玩具城（Ludibrium）** | ❌ **尚未开放** | 独立世界；预留资料：女神塔（通天塔）组队任务所在地 | Lv51~70（PQ 准入段） |
| **蘑菇城** | ❌ **尚未开放** | 独立世界（蘑菇主题区域） | Lv30~35 代表怪 |
| **地球防御本部** | ❌ **尚未开放** | 区外世界 | Lv46 代表怪 |
| **活动副本 / 隐藏街** | 随活动开关 | 限时活动区域，非常驻练级区 | 随活动 |

> **一转任务在彩虹岛接取、转职引导任务在明珠港**——接取入口与转职链全貌见文件02 §2.2。
> 金银岛地图共 **236 张**。

### 1.1.1 彩虹岛——旅程的起点

起点：彩虹岛蘑菇村，经南港乘船前往金银岛（详见文件16 §16.1）。

- **玩法定位**：创建角色、学基本操作（操作键位表见文件16 §16.1）、升到一转门槛（法师 8 / 其他 10）。
- **离开方式**：从岛上港口**乘船**前往金银岛明珠港，这是所有新手的第一次跨世界移动。
- 本服彩虹岛为**老版本布局**。

### 1.1.2 维多利亚大陆（金银岛）——主大陆

金银岛是 1~70 级的主战场，城镇自东向西大致为**明珠港、射手村、勇士部落、魔法森林、废弃都市、林中之城**等（城镇商店与 NPC 见文件10）。核心子区域：

| 子区域 | 代表地图/区域 | 怪物等级带 | 代表怪 |
|---|---|---|---|
| 明珠港 | 彩虹岛周边→明珠港郊外 | Lv1~10 | 新手区；转职引导任务入口（见文件02 §2.2） |
| 射手村 | 蘑菇林、射手村训练场 | Lv10~30 | 漂漂猪（Lv10）、绿蘑菇（Lv15） |
| 勇士部落 | 野猪领地、部落郊区 | Lv20~30 | 黑斧木妖（Lv22）、野猪（Lv25） |
| 林中之城（含地下迷宫） | 地下迷宫/蚂蚁洞；高贵之路特殊地图 | Lv27~62 | 火独眼兽（Lv27，蚂蚁洞）、怪猫（Lv62）；**蝙蝠魔剧情区**（开局剧情 BOSS，见文件05） |
| 魔法森林 | 魔法森林城镇及周边林域 | — | 法师系城镇（经典设定） |
| 废弃都市（含地铁） | 街道、地铁 | Lv32~48 | 鳄鱼（Lv32）、苔藓木妖（Lv48，地铁） |
| 石人寺院 | 金银岛外围山地 | Lv55~59 | 石头人（Lv55）、黑石头人（Lv58）、混种石头人（Lv59） |
| 龙族之地 / 龙族之巢 | 金银岛外围龙穴 | Lv60~68 | 赤龙（Lv60）、冰龙（Lv64）、黑恐龙（Lv68） |
| **黄金海滩** | 阳光沙滩等海滩区域（**当前已开放**） | Lv50~55 | **巨居蟹**（Lv55，BOSS，见文件05 §5.2.4） |

> 练级路线的"哪段等级去哪个子区域打哪只怪"在文件04 完整落地；本文件只给空间结构。

### 1.1.3 神秘岛（El Nath）——高等级区（❌ 尚未开放，预留资料）

> **🔴 神秘岛当前尚未开放**。

- **定位**：冰封雪域高等级区；预留资料：三转任务链在此的「长老公馆」进行（一转教官指引 → 复制体地图收集黑符 → 勇气项链 → 圣石答题 → 智慧项链，流程见文件02 §2.2.4；**三转与神秘岛均未开放**）。
- **世界归属**：**"隐藏地图"属神秘岛**，不属金银岛（判定见 §1.3 归属表）。
- **代表怪物**（均属区外，勿混入金银岛路线）：豪猪/灰豪猪、野狼、雪人、旱冰石头人——等级/回避与归属见 文件11 §11.3.5。

### 1.1.4 玩具城（Ludibrium）——女神塔所在世界（❌ 尚未开放，预留资料）

> **🔴 玩具城当前尚未开放**。

- **定位**：独立世界；预留资料：**女神塔组队任务（通天塔）的举办地**——该世界是女神塔 PQ 所在地，**PQ 参数与流程见 文件06 §6.5**。
- **玩法意义**：二转中后期经验与装备（女神项链）的重要产出渠道，是"练级卡在金银岛高级段"时的组队替代路线（**待该世界开放后方可用**）。

### 1.1.5 蘑菇城与其他区外区域（❌ 尚未开放，预留资料）

> **🔴 蘑菇城、地球防御本部等区外世界当前尚未开放**。

- **蘑菇城**：独立世界，代表怪得意的蘑菇仔（Lv30）、白雪人（Lv35）——世界归属判定见 §1.3 归属表。
- **地球防御本部**：外星章鱼激光棒 Lv46 的归属地，不属金银岛。
- **活动副本**：限时活动区域，内容随官方活动开关（见文件13），不纳入常驻练级/掉落模型。

## 1.2 版本环境：初期地图 = 经典布局

**对地图的含义**：本服**初期地图 = 经典版布局**（怪物位置、地图尺寸按老版本）；**迷你副本系统已从当前版本移除**，不计入地图/产出模型；大巨变后的地图布局与后期新大陆**不存在**（文件16 §16.5），世界清单以 §1.1 表为准。

> 上述结论所依据的原始版本调整条目见文件16 §16.3。

## 1.3 地图的世界归属（哪些地图属哪个世界）

> ⚠️ **命名相近 ≠ 同一世界**：下列区域有的名字看起来像区外、有的看起来像同一片区域，**实际归属相反**——判定时以本表为准，不要按名字字面推断。

| 区域 | 实际归属 | 是否金银岛 | 反直觉点 |
|---|---|---|---|
| 金银岛 | 维多利亚大陆 | ✅ | — |
| **迷宫** | **林中之城**（地下迷宫） | ✅ | 名字像独立区域，实际**属金银岛** |
| **高贵之路** | **林中之城**（特殊地图） | ✅ | 名字像区外，实际**属金银岛** |
| 废弃都市地铁 | 废弃都市（Kerning）子区域 | ✅ | — |
| 黄金海滩 / 迷你副本 / 潘姆之家 / 尤塔家 | 金银岛子区域 | ✅ | **黄金海滩当前已开放**；「迷你副本」系统已从当前版本移除（§1.2） |
| **隐藏地图** | **神秘岛**（El Nath） | ❌ 区外 | 名字像金银岛隐藏图，实际**属神秘岛** |
| **蘑菇城** | **蘑菇城**（独立世界） | ❌ 区外 | — |
| **玩具城** | **玩具城**（Ludibrium） | ❌ 区外 | 与「高贵之路」命名相近，归属**完全相反** |
| 冒险岛活动 / 히든스트리트 | 活动副本 | ❌ 区外 | 限时内容 |

> **归属纪律**：引用怪物练级/掉落时，区外区域（神秘岛 / 蘑菇城 / 地球防御本部 / 隐藏地图）的怪**不得混入金银岛路线**。

## 1.4 移动系统：从 A 到 B 怎么走

本服移动方式承袭经典版本，共四类机制：

| 方式 | 适用范围 | 典型场景 |
|---|---|---|
| **船** | 港口城镇间的跨海/跨大陆航线 | 彩虹岛 → 金银岛明珠港（新手第一次跨世界移动）；主大陆各港口城镇间客轮 |
| **飞行器** | 高等级独立世界间的空中航线（**神秘岛/玩具城等世界未开放，当前不可用**） | 预留资料：连接金银岛、神秘岛、玩具城等世界的城际航班 |
| **传送点（门/portal）** | 地图上的出入口，走到门处按键进入 | 林中之城地下迷宫入口、废弃都市地铁入口；神秘岛隐藏地图系列**未开放** |
| **计程车 / 步行** | 城镇内与道路沿线移动 | 计程车快速跨镇；沿道路逐图步行 |

- **职业技能移动**：法师**瞬移**（女神塔 PQ 硬性要求"会瞬移的法师"，见文件06 §6.5）、飞侠**轻功**（跳跃/位移，PQ 要求"满轻功飞侠"；技能见文件03）——移动能力本身就是组队玩法的准入条件。
- **特殊地图**：隐藏地图（神秘岛）需特定进入方式。

## 1.5 易错点

| # | 易错点 | 正确做法 |
|---|---|---|
| 1 | 把隐藏地图当金银岛的隐藏区域 | 属**神秘岛**，区外 |
| 2 | 把蘑菇城/玩具城当金银岛子区域 | 均为**独立世界** |
| 3 | 把迷宫、高贵之路误判区外 | 均属**金银岛**（林中之城） |
| 4 | 把「迷你副本」计入当前版本产出/路线模型 | 该系统已**从当前版本移除** |
| 5 | 区外怪物混入金银岛练级路线 | 属区外（神秘岛/隐藏地图等）——归属列见 文件11 §11.3.5，路线判定见 文件04 |
| 6 | **把神秘岛/玩具城/蘑菇城/地球防御本部当作当前可去区域** | **当前仅开放金银岛主大陆与黄金海滩**，上述世界**尚未开放**（文件16 §16.0） |
