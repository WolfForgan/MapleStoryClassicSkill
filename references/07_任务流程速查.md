# 07 - 任务流程速查

> **本文件讲什么**：任务系统本身怎么运作（游戏内操作）、任务有哪些类型、每类任务的完整链条、任务奖励构成、做任务时的实用提醒。转职体系的整体规则（转职等级、属性要求）在文件02，本文只从"任务"视角展开。

---

## 7.1 任务系统怎么运作（游戏内操作）

任务（Quest）是本服引导玩家成长的主线机制：升级、转职、获取勋章/特殊装备、解锁玩法，几乎全部通过任务串起来。游戏内的任务操作如下：

| 操作 | 说明 |
|---|---|
| **任务窗口（快捷键 Q）** | 打开任务告知栏，分三个页签：**可开始**（当前等级/前置满足、可去接取的任务）、**进行中**（已接未完成的任务及其目标进度）、**已完成**（交付过的任务，自动归档分类，便于回查剧情与奖励记录） |
| **NPC 头顶灯泡** | 可接取任务的 NPC 头顶有**黄色灯泡**；任务进行中的 NPC 头顶是**灰色灯泡**；可交付（完成条件已满足）时变回**黄色/绿色灯泡**。与 NPC 对话即可接取/推进/交付任务 |
| **小地图查 NPC 位置** | 任务进行中时，任务描述里会标注目标 NPC/怪物所在地图；按 M 打开地图（或小地图旁 NPC 列表）可定位该图上的 NPC 位置，避免瞎跑 |
| **任务告知栏提示** | 屏幕侧边的任务告知栏实时显示进行中任务的目标计数（如"打怪 12/100"），击杀类任务**队友的击杀数也可叠加计入**（见文件12 §12.8.2） |
| **接取条件判定** | 任务是否"可开始"由**等级区间 + 前置任务 + 职业限制**三者决定，任一不满足则任务不出现在"可开始"页签 |

> **⚠️ 背包留空（高频踩坑）**：多个转职类任务的奖励是**实物道具**（如二转的"介绍信"）。**背包满时奖励发不下来，任务会卡在无法交付的状态**。做二转等任务前先清背包。

## 7.2 任务类型分类体系

本服任务按功能可分为以下七类，各类的完整链条见后续小节：

| 类型 | 说明 | 详见 |
|---|---|---|
| **① 主线/引导任务** | 教学与转职引导，指明下一步玩法 | §7.3 |
| **② 转职任务** | 一转/二转/三转的接取与流程 | §7.3 |
| **③ 职业修炼链任务** | 一转后每级一段的练级引导任务 | §7.4 |
| **④ 修炼场任务** | 各职业专属修炼场的入场/挑战任务 | §7.4 |
| **⑤ 勋章/特殊装备来源任务** | 完成即得勋章或特定装备 | §7.5 |
| **⑥ 日常/限时任务** | 有刷新周期或截止时间的任务 | §7.6 |
| **⑦ 组队任务（PQ）** | 任务图鉴中的**独立分类**，多人协作玩法，规则与普通任务不同 | 文件06 |

## 7.3 转职任务链（一转 / 引导 / 二转 / 三转）

### 7.3.1 一转任务与引导任务

一转是角色从"初心者"进入职业体系的关键节点。**任务侧的关键差异**：一转任务（五大职业系各有一条对应任务）与转职引导任务的接取条件**只卡等级区间**（法师 8 级、其他职业 10 级，任务详情显示「等级 ≥ 10 且 ≤ 20」，无属性条件）；而各职业的**属性要求是转职教官 NPC 的对话条件**，不是任务接取条件。

> **转职入口、一转/二转教官名录与各职业属性要求见文件02 §2.2.8，此处不重复。**

### 7.3.2 二转任务（30 级）

30 级后回到本职业**一转教官**处接二转任务 → 进入**二转考验场**收集 **30 个黑珠** → 交回教官 → **选择二转分支**（如战士在剑客 / 准骑士 / 枪战士三线中三选一）。

> ⚠️ 做二转前**务必背包留空**（介绍信类奖励道具发不进满背包）。

### 7.3.3 三转任务（70 级，❌ 尚未开放，预留资料）

> **🔴 当前版本三转尚未开放**。三转流程属后续版本预留资料，**完整流程见 文件02 §2.2.4**，本文件不重复。

## 7.4 职业修炼链与修炼场任务（游戏内「职业」分类任务）

一转完成后，各职业有一条**逐等级推进的修炼任务链**（Lv 每 +1 解锁下一段），引导玩家在职业相关地图练级；另有**各职业专属修炼场任务**（战士/法师/弓箭手/飞侠/海盗各一），指向本职业专属修炼场地图。

> **各职业修炼链的具体等级跨度表见文件02 §2.2.6，此处不重复。**

> **🔴 修炼任务的奖励（高频误解）**：修炼链与修炼场任务的奖励只有**药水 + 经验**，**不发技能点（SP）**——SP 发放见 **§7.8**。

## 7.6 日常 / 限时任务

- 游戏内存在带**刷新周期或截止时间**的任务（日常类、活动限时类）。这类任务错过窗口即不可再接，需要节奏管理。
- 「**999 任务计时**」是玩家侧的提醒工具（管理日常节奏），**不是游戏内系统**，勿与游戏内任务混淆。
- 活动限时任务随版本活动上下线，**没有固定清单**（见文件13 §13.4）。

## 7.7 组队任务（PQ）——独立分类

任务图鉴中「**组队任务**」是**独立分类**，与普通任务规则不同：需要多人组队进入专属副本、有职业搭配要求、奖励为印记/项链类专属物品。**具体条目、等级、职业搭配与流程详解见文件06，此处不重复。**

## 7.8 任务奖励的构成规律

| 奖励类型 | 出现于 | 说明 |
|---|---|---|
| **经验值** | 几乎所有任务 | 前期任务经验占升级收益的显著比例，是"任务优先于纯刷怪"的核心理由 |
| **药水/消耗品** | 修炼链、转职链、新手任务 | 如各类回 HP/MP 药水 |
| **实物道具**（介绍信/凭证/项链等） | 转职链 | **占用背包格**——背包满会卡任务交付（§7.1 提醒） |
| **装备/勋章** | 发型变换达人、陌生女人的真相等来源任务 | 见 §7.5 |
| **SP** | ❌ **任何任务都不发 SP** | SP 只由等级与转职独立发放（**每级 3 点 + 每次转职赠送 1 点**，见文件02 §2.3.1）；修炼任务"看起来给了很多"是药水+经验，不是技能点 |

## 7.9 游戏内问答类任务

游戏内 NPC **瑞恩**的新手引导问答中，「升级时**增加 1 点**技能值」的文案与实际不符——**以每级 +3 点为准**（见文件02 §2.3.4、§7.8）。

## 7.10 易错点汇总

| # | 易错点 | 正确做法 |
|---|--------|----------|
| 1 | 把瑞恩问答文案当规则 | SP 以每级 +3 公式为准（§7.9） |
| 2 | 忽略背包留空 | 二转等任务奖励是实物道具，背包满会卡交付（§7.1） |
| 3 | 用旧版任务流程 | 旧版任务流程文档不可直接套用 |
| 4 | 把修炼任务当 SP 来源 | 修炼任务只给**药水+经验**，SP 由等级公式独立发放（§7.4） |
| 5 | 从任务接取条件找转职属性门槛 | 游戏内转职任务**只卡等级**；属性要求是教官 NPC 对话条件 |
| 6 | 把组队任务当普通任务 | 「组队任务」是独立分类，规则不同（§7.7、文件06） |
| 7 | 以为任务能补 SP/给技能点 | 任何任务都不发 SP（§7.8） |
| 8 | 按任务名称猜职业归属 | 按任务详情标注的**职业系**判定，不按任务名称猜 |
