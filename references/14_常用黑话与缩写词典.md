# 14 - 常用黑话与缩写词典

> **本文件讲什么**：让玩家社区语言"能被准确理解"的完整词典。每条给**术语 / 英文或字段名 / 含义 / 备注**。回答玩家问题时先在此核对术语的真实所指——本服大量"黑话"与正式服、与行情数据的字面含义**并不一致**（见 §14.7 陷阱词）。

## 14.1 货币与交易术语

> 机制全文见文件09 §9.6~§9.8（四币种、三渠道、手续费核定）。

| 术语 | 英文/别名 | 含义 | 备注 |
|---|---|---|---|
| 金币 | meso | 游戏内产出货币（打怪/任务/卖物） | 可交易、不可提现；摆摊**只收金币** |
| 抵用券 | Maple Point | **按人民币价值计价的消费券**，可交易、拍卖场可结算 | 来源：活动/补偿/交换券；🔴 与点券不是一回事 |
| 冒险券 / 点券 | Cash | **充值货币** | **1 元 = 100 点券**（固定比例）；冒险券→抵用券官方固定 1:1 |
| 积分 | Reward Point | **消费返利**（仅来自消费冒险券），不可交易 | 🔴 与"站点积分"（§14.6）完全不同，勿混 |
| 物品桥 | — | 金币→抵用券的**间接转换路径**：金币买可交易物品 → 物品经拍卖行以抵用券结算 | **金币→抵用券无官方直接通道**，只能过物品桥 |
| 面对面交易 | trade | 同图玩家直接交换金币/抵用券与物品 | 即时交割；**涉及金币结算抽 5% 税**；**风控敏感度最高**（高频大额易触发预警）；绑定道具不可转移 |
| 摆摊 | 个人商店/雇佣商店 | **自由市场**离线/在线开店卖货 | **仅金币**结算；需商城**商店许可证**（1 天/7 天） |
| 自由市场 | Free Market | 摆摊生态的统称，CV001 开服回归特性 | "重回经典自由市场"是官方卖点 |
| 拍卖行 / 拍卖场 | Auction | 全服可见的系统中介交易 | 金币/抵用券双计价 |
| 手续费 | 交易税 | 交易时按成交价抽取的费用 | **拍卖行成交 5%、面对面·金币结算 5%**；**摆摊与面对面·抵用券结算尚无定论** |
| 官方金币交易平台 | — | **盛趣官方**运营的金币交易平台 | 2026-08-03 开怀旧服专区、2026-08-18 手续费上调至 2% |
| 打金 / 搬砖 | — | 打怪刷金币变现/自给 | — |
| RMT | 现实货币交易 | 用人民币买卖游戏内资源 | 助手不提供 RMT 信息，金价仅作行情参考 |

## 14.2 属性与面板术语

> 公式全文见文件12 §12.1~§12.3。

| 术语 | 英文/字段名 | 含义 | 备注 |
|---|---|---|---|
| 力量 | STR / `str` | 主属性之一；战士/拳手主属性 | 每属性自带**底值 4**（不占 AP） |
| 敏捷 | DEX / `dex` | 弓手/枪手主属性；给命中与回避 | 1 DEX = 命中 +0.8（弓/飞 +0.6）、回避 +0.25 |
| 智力 | INT / `int` | 法师主属性；MATK/MDEF 各 1:1 吃 INT | 法师"一鱼三吃"：MATK+MDEF+魔法命中 |
| 运气 | LUK / `luk` | 飞侠主属性；命中 +0.5（弓/飞 +0.3）、回避 +0.5 | 法师副属性 LUK 仅展示不参与伤害 |
| 人气 | Fame | 社交数值，15 级解锁，每天 1 点、同目标每月 1 次 | 部分装备穿戴门槛；可出售换金币（早期 6000~8000/点） |
| WATK | `watk` 物理攻击力 | 物理攻击力**标量**（由装备/技能 pad 构成） | 🔴 **与属性点完全无关**（常见误解见 §14.7）；公式见文件12 §12.1.3 |
| MATK | `matk` 魔法力 | 魔法力（INT 直接 1:1 进入） | 公式见文件12 §12.1.3 |
| pdef / wdef | 物理防御 | 物理防御 | 与属性点无关；公式见文件12 §12.1.3 |
| mdef | 魔法防御 | 魔法防御（INT 1:1 进入） | 公式见文件12 §12.1.3 |
| acc | 命中 | 命中值，决定打不打得中 | 满命中需求公式见文件12 §12.3 |
| avoid | 回避 | 怪物回避=命中需求的乘数项；角色回避=被命中率折减 | — |
| hands | 手技 | 手技（与合成类玩法相关） | 公式见文件12 §12.1.3 |
| mastery | 熟练度 | 技能数值（精准武器类） | 🔴 **只折损面板下限，不折损上限**——"稳定器"不是"放大器"；clamp 值见文件12 §12.1.3 |
| attackSpeed | 攻速 | 攻速等级（如"快(5)"） | 来源：武器基础 + 技能（快速剑等）+ 增益 |
| panelMin / panelMax | 面板攻击下限/上限 | 面板"攻击力"是**区间**不是单值（§14.7） | 公式见文件12 §12.1.3 |
| HP / MP | 生命值/魔力值 | 基础成长 + 装备 + 生命加强（战士专属）+ 增益率 | 生命加强 Lv90 满级约 +3,060 HP，仅战士 |
| AP | 属性点 Ability Point | **总量 = 4 + 5×Lv** | 初始 4 点 + 每级 +5 |
| SP | 技能点 Skill Point | **总量 = 3 × (Lv − 一转等级) + 转职次数** | **每级 +3、每次转职赠送 1 点**（一转 61 点 / 法师 67 点 / 二转 121 点）；修炼任务**不发 SP** |
| 裸属性 | — | 角色自身 AP 投入 + 固有属性，不含装备加成 | 仅作参考概念；**穿戴属性门槛不以裸属性为限**——其他部位装备（含卷轴）的属性也可计入 |
| 面板 | panel | 能力值窗口显示的总属性/总战力 | 面板值 = 基础 + 装备 + 卷轴 + 技能 + 增益；🟢 判穿戴时**可用"基础 + 其他部位装备（含卷轴）"**，但**不可用目标装备自身属性** |
| 武器系数 | swing / stab | 各武器类型的伤害乘数（单手剑 4.0 … 枪 3.0/5.0） | swing≠stab 时两系数各算一次，min 取小 max 取大 |

## 14.3 玩法术语

| 术语 | 英文/别名 | 含义 | 备注 |
|---|---|---|---|
| 砸卷 / 砸券 / 上卷 | 卷轴强化 | 对带槽装备使用卷轴搏属性加成 | **本服装备强化唯一途径**；无升星/洗炼/合成升级 |
| 卷轴槽 | 「可使用卷轴次数」 | 装备**剩余可砸卷次数** | 🔴 是潜力上限，**不是已强化次数** |
| 诅咒卷 | cursed scroll | 高加成卷轴，**失败会毁坏装备** | 与普通失败（仅损失卷轴）不同；`cursed` 字段标记 |
| 满槽 / 满 ID | — | 装备卷轴槽**全部用完**（剩余次数=0） | 常见于晒装备语境；"全 ID"同义 |
| 白板 | — | 未砸任何卷轴的裸装备 | 与"底装"（强化前基础装备，配装语境）近义 |
| 底装 | — | 用作强化基础的未强化装备 | 选底装看槽数与职业匹配（文件08 §8.8） |
| 一转 / 二转 / 三转 | job advancement | 职业进阶节点：8/10 → 30 → 70 级 | **当前封顶二转、等级上限 100，三转尚未开放**（文件16 §16.0）；无四转/五转 |
| 转职 | — | 进入下一段职业（含选分支） | 任务链见文件07 §7.3 |
| 修炼场 | — | 各职业专属练级地图（修炼链任务） | 修炼链任务只给药水+经验 |
| 练级 | grinding | 打怪升级 | 路线见文件04 |
| 越级 | — | 打高于自己等级的怪 | 命中需求含**越级罚项**（每差 1 级需求 +2.15×回避÷15） |
| 大乱斗 | — | 玩家扎堆抢同一高密度练级点的混战生态 | 经典场景：黑鳄鱼（Lv52）所在图 |
| 蹲点 | — | 固定占据某刷新点练级/等 BOSS | BOSS 按频道独立刷新，可换频道蹲（文件05） |
| 刷图 | — | 循环清理某地图怪物 | — |
| 开荒 | — | 首次推进未打过的 BOSS/副本/等级段 | — |
| 起号 | — | 从零培养一个新角色 | 起号路线=转职+练级+配装的组合规划 |
| 养老 | — | 高等级后低强度休闲玩法（摆摊/收藏/外观） | 契合本服"慢节奏"基调 |
| CD | cooldown | 技能冷却 | — |
| 频道 | channel | 同服并行的多条世界线 | 登录时选频道；BOSS 状态**按频道独立**刷新 |
| 同图 | — | 队友与自己在同一张地图 | 组队经验共享的硬条件之一（文件12 §12.8.1） |
| PQ | Party Quest | 组队任务（副本式协作玩法） | 游戏内任务图鉴有独立「组队任务」分类，见文件06 |
| 卡级 / 压级 | — | 停在某等级不升（攒 SP/等装备/等转职） | — |

## 14.7 陷阱词专区（🔴 每条都会导致错误结论）

| 陷阱说法 | 表面理解 | 实际情况 |
|---|---|---|
| 「攻击力」 | 一个数 | 面板"攻击力"是 `${min}~${max}` **区间**；`watk` 才是标量且不含属性点（文件12 §12.1.1） |
| 「可使用卷轴次数：7」 | 已强化 7 次 | 陷阱词：**不代表已强化**（实为剩余可砸次数），详见 §14.3 |
| 「积分」 | 游戏内货币/可交易 | 游戏内积分=消费返利，不可交易 |
| 「手续费 5%」 | 每个渠道都收 5% | 陷阱词：**并非所有渠道都收 5%**，具体渠道见 §14.1 |
| 「升级 +1 点技能值」 | 规则 | 瑞恩问答旧文案未同步，实际每级 +3（文件07 §7.9） |
| 「剑客是二转还是三转」 | 名称记忆 | **剑客=二转、勇士=三转**；职业段位一律以游戏内实际职业全名为准（文件02 §2.1） |
| 「面板属性够就能穿」 | 达标 | 穿戴属性门槛**可计入其他部位装备（含卷轴）提供的属性**——但**不能拿目标装备自身的属性来凑**（文件08 §8.3） |
| 「商城价 1000 = ¥1000」 | 1:1 人民币 | 商城标价是**点券**：1000 点 = ¥10（1 元=100 点） |

## 14.8 职业黑话速对

| 黑话 | 说明 |
|---|---|
| 战士 / 剑客 / 骑士 / 龙骑 | 近战物理；⚠️ "骑士"可指三转的骑士/圣骑士，**必须回游戏内的职业全名** |
| 法师 / 冰雷 / 火毒 / 牧师 | 魔法攻击 |
| 弓手 / 弩手 | 远程物理 |
| 标飞 / 刀飞 | 飞侠分支 |
| 拳手 / 船长 | 海盗分支，完整三段 |
| 满命中 / 满回避 | 命中/回避达到目标怪物需求的达标状态，公式见文件12 §12.3 |

> **⚠️ 铁律**：职业**一律以游戏内实际职业全名为准**（存在"骑士"这类易混名称——它可指三转的骑士/圣骑士，与二转的准骑士不是一回事）；职业清单以文件02 §2.1.2 为准，表外职业名一律不采。
