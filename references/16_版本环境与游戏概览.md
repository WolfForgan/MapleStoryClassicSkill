### 16.1.1 世界观与开局

彩虹岛上的蘑菇村，村民安居乐业。村中四种职业——**战士、魔法师、弓箭手、飞侠**——备受尊敬，每年其优秀代表要到**金银岛**狩猎并展示技艺。两个小伙子小强和小乖偷偷登上前往金银岛的船，跟随冒险小组行动。冒险小组的最后一个任务是挑战史前巨兽**蝙蝠魔**（一种变异并学会魔法的蝙蝠），小强小乖尾随进入地下迷宫，被蝙蝠魔抓走——消息传回彩虹岛，许多人赶赴金银岛展开大规模搜救。**这就是玩家登岛的故事起点。**

> 由此可知新手动线：**彩虹岛（出生/教学）→ 乘船 → 金银岛（主城与练级）**。当前版本**仅开放金银岛主大陆与黄金海滩**，更高等级世界尚未开放。

### 16.1.2 配置要求

| 项目 | 最低 | 推荐 |
|---|---|---|
| CPU | Intel Core 2 Duo @3.0GHz / AMD Athlon 64 X2 @3.0GHz | Intel Core i3 @4.0GHz / AMD Ryzen 3 @3.5GHz |
| 内存 | 4GB | 8GB |
| 硬盘 | 5GB 以上 HDD | 10GB 以上 SSD |
| OS | Windows 10 (64 bit)，建议最低 1703（推荐 1903） | 同左 |
| 显卡 | GeForce 9600 GT 或 ATI Radeon HD 5670 | GeForce GTX 1050 / AMD Radeon RX 570 及以上 |
| DirectX | 11.0 以上 | 11.0 以上 |

> 配置表**无分辨率项**；展示图片分辨率为 **1366×768**。

### 16.1.3 登录与创角

- **登录窗**：账号 + 密码 + **连接**；支持**自动登录 / 注册账号 / 忘记密码**；三种登录方式页签为 **密码登录 / 一键登录 / 二维码**；界面标 **12+ CADPA 适龄提示**。
- **登录流程**：启动客户端 → **选择大区** → 输入通行证账号密码登录 → **选择服务器与频道** → 创建角色开始。
- **创角流程**：点「创建角色」→ 参考职业介绍选择职业 → 输入角色名并**点查重**（避免重名或含禁用词）→ 选性别与脸型 / 发型 / 外观颜色（**部分职业无法调整外观**）→ 确定。
- **角色选择界面**三选项：**开始游戏 / 创建角色 / 删除角色**。

### 16.1.4 游戏设置

- **入口**：游戏底部工具栏的**菜单**按钮，**或直接按 `Esc`**；菜单内进「游戏设置」。
- 设置窗共**三个页签**：
  - **画面**：分辨率（如 1366×768）；**显示血量警告 / 魔量警告**滑条；**怪物信息显示**。
  - **声音**：**主音量 / 背景音乐 / 音效**，各有滑条与静音。
  - **社交**：**对话请求**（悄悄话 / 家族对话 / 好友对话 / 对话邀请 / 同盟对话）；**队伍&社交**（邀请组队 / 家族邀请 / 寻找队伍 / 同盟邀请）；**交易**（交易申请）——均可勾选"允许"。
- 提示：不同分辨率下各功能部件位置略有不同；分辨率可在**菜单—游戏设置**里修改。

## 16.3 5·30《改进方向说明》——本服机制的定调文件

### ① 交易系统调整

| 项 | 内容 |
|---|---|
| A | **移除**金币绑定游戏角色的设定 |
| B | **添加面对面交易**（可选金币或抵用券） |
| C | **拍卖场添加金币作为交易货币**（可选金币或抵用券） |
| D | **添加自由市场个人商店 / 雇佣商店**（通过金币交易） |
| E | **交易手续费从 10% 调整到 5%** |

### ② 游戏内容调整

| 项 | 内容 |
|---|---|
| A | **移除**因后续版本更新导致的初期地图变动：<br>　i. 移除彩虹岛、金银岛**怪物位置变动**事项<br>　ii. 移除彩虹岛**地图大小变动**事项 |
| B | **迷你副本系统从当前版本中移除** |
| C | 对和过去有差异的部分进行调整：血条及药水的颜色、技能特效等 |

> **含义**：本服**初期地图 = 经典版布局**（怪物位置、地图尺寸按老版本）；**迷你副本在本服不存在**（做掉落/产出模型时不要计入它）。

### ③ 现金道具调整

| 项 | 内容 |
|---|---|
| A | **移除**蘑菇通行证中的装备类道具、**移除**飞天猪的蛋中的装备类道具 |
| B | 对部分现金道具进行调整 |

> **含义**：现金抽奖/通行证**不再直接产出装备** → 装备来源收敛为"掉落 + 卷轴强化 + 制作 + 交易"，这是经济模型的重要前提。

## 16.8 新手指引要点

> 以下为新手阶段的操作要点，以游戏内实际为准。

### 16.8.1 属性自动分配

- **1 转或 11 级之前，属性按本职业特性自动分配**；完成**一转后**这些自动分配的点数会**全部回到「能力点」**，由玩家**重新分配**。
- ⚠️ 与文件12 §12.11.2 的说法不一致（该处写「一转完成前系统默认把点数加到力量上」）——**两处说法不一致，以游戏内实际为准**。

### 16.8.2 第一次升级

- 完成任务 / 打怪获得经验，经验累计即升级。
- **升级获得技能点与能力值自由分配点**。

### 16.8.3 任务

- 点 NPC 头顶**灯泡** → 对话推进 → 选「**下项**」→ 打开任务窗 → **接受**；交付后获得经验与奖励。任务窗口页签、快捷键与接取条件判定见文件07 §7.1。

### 16.8.4 第一次打怪

- 新手阶段用**普通攻击**（键位分歧见 §16.1.5）。
- **被怪物碰到会被击退**。
- 击败怪物掉落物品，按 **`Z`** 拾取。
- 血量 / 魔量不足时打开背包**「消耗」页**双击使用药水；推荐**把药水拖到快捷键**便于补给。

### 16.8.5 释放技能

- 快捷键 **`K`** 打开技能窗。
- 点技能行右侧的**橙色「+」**升级技能。
- **技能放上快捷栏需两步**：左键点技能 → 放到键位 → **再单击鼠标**。

### 16.8.6 组队

- 两种入口：**右键他人 →「组队邀请」**，或在**好友菜单（`R`）**内进行**组队邀请 / 组队招待**；对方同意后进入组队状态。**好友上限 20**。
- 队伍上限、经验分配、等级差、同图要求、邀请失效时限等规则见文件12 §12.8.2。

### 16.8.7 物品与背包

- 药水在背包**「消耗」页**，**双击**使用。
- **道具窗口放不下时**可**存入仓库**，或在**商城内用点券扩充窗口数量**。
- **道具栏六页签**见 §16.1。
