# 10 - NPC图鉴与商店

> **本文件讲什么**：NPC 系统是什么、关键 NPC 名录（转职/引导/问答类）、金币商店与游戏商城两套"商店"体系的区别、NPC 制作与合成两套打造系统，以及商城定价（点券计价）。摆摊/交易机制见文件09 §9.8，人气见文件02 §2.6、勋章见文件07 §7.5。

---

## 10.1 NPC 系统是什么

NPC（非玩家角色）是本服功能系统的**交互入口**：转职、任务接取与交付、买卖物品、仓库、传送、制作、美容，全部通过对应 NPC 完成。玩家与游戏机制的绝大多数接触面都"长"在 NPC 身上——找不到 NPC 就等于找不到功能。

## 10.3 两套"商店"：金币商店 vs 游戏商城

本服的"商店"是两套完全不同的体系，货币、入口、商品性质都不一样：

### 10.3.1 金币商店（NPC 商店）

- **是什么**：NPC 开设的买卖铺子，用**金币（meso）**结算。玩家可**卖出**打怪拾取/制作的物品换金币，也可**买入**基础补给（药水、箭矢、基础装备等）。
- **兜底价机制**：NPC 商店对部分物品有**固定收购/出售底价**——它构成物价的"地板"（下限锚点）；卷轴类具体价目见 **文件09 §9.5.1**。
- 玩家间交易不走 NPC 商店——摆摊/拍卖行/面对面三渠道见文件09 §9.8。

### 10.3.2 游戏商城（现金商店）

- **是什么**：现金道具商店，**以点券计价**。
- 商城的点券换算规则、以及「商城直购价构成金币价上限」的换算规则，统一见 **文件09 §9.9**。

### 10.3.3 商城关键道具与功能（游戏内容层面）

| 商城功能/道具 | 说明 |
|---|---|
| **商店许可证** | **自由市场摆摊的前提道具**：商城购买，有 **1 天 / 7 天**时效两档；没有许可证无法开个人/雇佣商店（摆摊机制见文件09 §9.8.2） |
| **皇家美容 / 皇家美发** | 外观服务：**理发券**（皇家理发券 / 经典皇家理发券）用于更换发型/脸型外观；同时是**「发型变换达人」任务（产出美发潮人勋章）的消耗材料（需 50 张）**（见文件07 §7.5） |
| **抵用券交换券** | **换取抵用券**的道具（面额系列、🔴 同名陷阱等细节见文件09 §9.5.3） |
| **喇叭类** | **世界聊天广播道具**（喇叭清单见文件09 §9.5.2） |
| **生命水（宠物）** | 宠物用商城道具（点券计价，价格见文件09 §9.5.2、§9.9） |
| **背包扩容** | 道具窗口放不下时，可在商城用点券扩充窗口数量（见文件16 §16.1） |
| **现金保管箱** | 商城提供的账号级仓库：**同账号跨角色共用**（账号内角色间转移现金道具的通道，非跨账号）。现金道具来源：商城点券直购 / 商城活动礼包抽取；**现金道具亦可在拍卖行买卖**（机制见文件09 §9.8.2b） |

> **抵用券 ≠ 点券**：点券（冒险券）是充值货币；抵用券是**按人民币价值计价的消费券**（可交易、拍卖场可结算），来源为**充值后在商城购买**、**拍卖行以抵用券定价售出物品**、活动/补偿/交换券。四币种区分见文件09 §9.6，勿混算。

## 10.4 NPC 制作与合成：两套打造系统

装备/道具产出侧有两套"打造"系统，**唯一关键区别在"失败怎么算"**：

- **NPC 制作**：特定功能 NPC（铁匠、裁缝类）提供的**制造服务**——向 NPC 交材料（+手续费）换取成品，**交材料必出**。
- **合成**：**玩家角色自带**的合成技能（收益与角色**手技 hands** 属性相关）——把材料按配方组合，属**概率判定**，**失败损失材料**。

> 打造系统全貌（配方、材料、产出与装备获取全途径）见 **文件08 §8.6**。

## 10.5 易错点汇总

| # | 易错点 | 正确做法 |
|---|--------|----------|
| 1 | 把商城价格当人民币 | 是**点券**（1 元 = 100 点）；1000 点 = ¥10，误读放大 100 倍 |
| 2 | 摆摊不买许可证 | 见 §10.3.3（商店许可证） |
| 3 | 用旧版 NPC 位置 | 以 NPC 图鉴的所在地图为准 |
| 4 | 引用瑞恩问答当规则 | 涉及技能值的问答是旧文案未同步，SP 以每级 +3 公式为准 |
| 5 | 金币商店价与商城价直接比大小 | 两套货币（金币 vs 点券），比较须经汇率换算（文件09 §9.9） |
| 6 | 把抵用券当点券 | 见 §10.3.3（抵用券 ≠ 点券） |
| 7 | 把同名抵用券交换券当同一种 | 见 §10.3.3（抵用券交换券同名陷阱） |
| 8 | 把合成当必出成品 | 合成有**成功率**，失败损失材料；NPC 制作才是交材料必出 |
